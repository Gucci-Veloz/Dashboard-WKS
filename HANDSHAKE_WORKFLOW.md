HANDSHAKE_WORKFLOW

# Flujo de trabajo de la habilidad: Handshake → Scavenge → Mapping → Aprobación

## 01 — Handshake

**ENTENDER**

# Primero, que entienda tu idea.

```text
┌──────────────────┐              ┌─────────────────────────────────┐
│       TÚ         │     ↔        │         SESIÓN MAESTRA          │
│                  │              │                                 │
│ La idea          │              │ Tu chat principal               │
│                  │              │ Coordina y revisa               │
└─────────┬────────┘              └──────────────┬──────────────────┘
          │                                      │
          └──────────────────┬───────────────────┘
                                                          ↓
                  ┌─────────────────────────┐
                  │     Acuerdo escrito     │
                  └─────────────────────────┘
```

Aclaras el resultado, los límites y cómo comprobarlo. Tú confirmas antes de seguir.

---

## 02 — Scavenge

**INVESTIGAR**

# Dale contexto antes de pedirle un plan.

```text
┌──────────────────────┐     
│ FUENTES              │
│                      │
│ • Archivos           │
│ • Datos              │        
│ • Referencias        │     
└──────────┬───────────┘
           │                 ┌─────────────────────────────────┐
           │                 │ ✓ HECHOS                        │
           │                 │                                 │
           │                 │   Con evidencia                 │
           │                 └─────────────────────────────────┘
           └──────────────→  
                             ┌─────────────────────────────────┐
                             │ ? VACÍOS                        │
                             │                                 │
                             │   Lo que falta saber            │
                             └─────────────────────────────────┘
```

El investigador reúne fuentes, verifica datos y señala lo que falta.

---

## 03 — Mapping

**PLANEAR**

# Una tarea clara para cada agente.

```text
                         ┌───────────────────────┐
                         │     PLAN ESCRITO      │
                         └───────────┬───────────┘
                                     │
              ┌──────────────────────┼──────────────────────┐
                            ↓                                             ↓                                            ↓
┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
│ TAREA 01            │ │ TAREA 02            │ │ TAREA 03            │
│ ─────────────────── │ │ ─────────────────── │ │ ─────────────────── │
│ • Contexto          │ │ • Contexto          │ │ • Contexto          │
│ • Instrucciones     │ │ • Instrucciones     │ │ • Instrucciones     │
│ • Pruebas           │ │ • Pruebas           │ │ • Pruebas           │
└─────────────────────┘ └─────────────────────┘ └─────────────────────┘
```

El planificador define tareas, entregas y pruebas.

Así puedes asignarlas a agentes de menor costo.

---

## 04 — Aprobación

**AUTORIZAR**

# Tú das luz verde.

```text
┌────────────────────────┐
│ LA MAESTRA             │
│                        │
│ Revisa el plan         │
└────────────┬───────────┘
             │
             └──────────────→  ┌─────────────────────────────┐
                               │ ✓ TÚ                        │
                               │                             │
                               │ Das luz verde.              │
                               │ ─────────────────────────── │
                               │ O ya lo permitiste          │
                               │ por escrito.                │
                               └─────────────────────────────┘
```

La maestra contrasta el plan con lo acordado.

Tú autorizas, salvo tus reglas previas.
